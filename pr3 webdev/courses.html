Computer Science and Engineering is one of the most popular engineering programs. It focuses on software development, programming, networking and modern computer technologies.

Subjects Covered:

  • C Programming
  • C++ Programming
  • Java Programming
  • Python Programming
  • HTML
  • CSS
  • JavaScript
  • Data Structures
  • Database Management System (DBMS)
  • Operating System
  • Computer Networks
  • Web Technology

Information Technology (IT)

Information Technology focuses on computer applications, networking, cybersecurity and software development.

Subjects Covered:

  • Programming in C

  • Python

  • Cloud Computing
  • Cyber Security

Mechanical Engineering

Mechanical Engineering deals with machines, manufacturing, robotics and thermal engineering.

Civil Engineering focuses on construction, structural design, transportation and environmental engineering.
